# Changelog

All notable changes to Lightware Monitor are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-30

### Added
- Initial public release
- Real-time CPU usage, GPU temperature, and FPS overlay
- Always-on-top overlay that works in fullscreen games
- Click-through mode (overlay ignores mouse input by default)
- 4 built-in themes: Cyberpunk Neon, Stealth White, Crimson Fury, Aurora Green
- Mini mode (compact bar) toggleable via double-click or tray menu
- Resizable normal mode with auto-scaling text
- Unlock combo: Left Ctrl + Left Shift to enable drag, resize, close
- Tray icon with right-click menu (themes, mode, reset, auto-start)
- Persisted settings (position, size, theme, mode, font size)
- Touch-and-hold support for handheld devices (1.5s to unlock)
- Self-contained build — no .NET runtime installation required
